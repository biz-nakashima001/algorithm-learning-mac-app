# Little by Little — アルゴリズム学習アプリ

SwiftUI で作られた、アルゴリズムの動きを一手ずつ見て学ぶ macOS アプリの試作です。並べ替えや値の検索で起きる比較・移動を、配列の表示、短い説明、擬似コードを通して確認できます。

## 目的・対象ユーザー・試作の要件

### 目的

アルゴリズムをコードだけでなく、各ステップで何を比べ、どのように状態が変わるかを見ながら理解できるようにします。

### 対象ユーザー

- アルゴリズムを初めて学ぶ人
- 並べ替えや検索の基本を復習したい人
- 擬似コードと実際のデータの変化を対応づけて学びたい人

### 試作の要件

- 並べ替えと検索の基本アルゴリズムを選択できる
- アルゴリズムの処理を一段階ずつ進めたり、自動再生・一時停止したりできる
- 比較中の値や、並べ替え済みの範囲を色で示す
- 現在の処理を初心者向けの短い説明で示す
- 説明に対応する擬似コードの行を強調する
- 比較回数と時間計算量の目安を表示する
- 検索対象の値を編集し、新しいサンプルデータを生成できる
- 日本語・英語・簡体字中国語を切り替えられる

## 画面・操作の基本設計

画面は、左側のアルゴリズム選択エリアと、右側の学習エリアで構成します。

### アルゴリズム選択エリア

「SORTING（並べ替え）」と「SEARCHING（検索）」に分けてアルゴリズムを一覧表示します。並べ替えは選択ソート、バブルソート、挿入ソート、クイックソート、マージソートの順です。選択中のアルゴリズムは色で区別します。

### 学習エリア

1. **アルゴリズムの紹介** — 名前、分類、処理の概要を表示します。
2. **データの可視化** — 値をタイルで並べ、現在確認している値を青、並べ替え済みの値を緑で示します。検索アルゴリズムでは検索対象を編集できます。
3. **再生コントロール** — 最初に戻る、自動再生／一時停止、次のステップへ進む操作と、再生速度の調整を行います。現在のステップ番号と比較回数も表示します。
4. **学習情報** — 現在の処理の説明と、対応する擬似コードを並べて表示します。擬似コードでは処理中の行を強調します。

右上のボタンから新しいサンプルデータを作成できます。検索アルゴリズムでは、初期状態および新しいサンプルの検索対象を、データに含まれる値から設定します。二分探索を選ぶと、探索前にデータを昇順に並べます。画面右上の言語メニューから、日本語・英語・簡体字中国語を選択できます。選んだ言語は次回起動時にも使われます。

## 対象アルゴリズムと学習内容

| 分類 | アルゴリズム | 表示する処理の要点 | 時間計算量の目安 |
| --- | --- | --- | --- |
| 並べ替え | 選択ソート | 未整列の範囲から最小値を選び、先頭へ移す | O(n²) |
| 並べ替え | バブルソート | 隣り合う値を比較し、順序が逆なら入れ替える | O(n²) |
| 並べ替え | 挿入ソート | 左側の整列済み範囲を広げながら、値を適切な位置へ挿入する | O(n²) |
| 並べ替え | クイックソート | pivot を基準に値を分け、左右の範囲を再帰的に整列する | 平均 O(n log n)、最悪 O(n²) |
| 並べ替え | マージソート | 範囲を半分ずつ分割し、整列した範囲を併合する | O(n log n) |
| 検索 | 線形探索 | 左から順に値を比較し、対象を探す | O(n) |
| 検索 | 二分探索 | 中央の値を調べ、探索範囲を半分ずつ絞る | O(log n) |

計算量は、データ数が増えたときに処理量がどう増えるかを知るための目安として表示します。二分探索は整列済みのデータを前提とします。

## 実行方法・必要環境

- macOS 14 以降、または iOS 17 以降
- Swift 6 と SwiftUI を利用できる環境（Xcode 推奨）

### Xcode から実行

このフォルダを Swift Package として Xcode で開き、`AlgorithmLearning` を実行します。

### ターミナルから実行

プロジェクトのフォルダで次を実行します。

```sh
swift run
```

### iPhone 向けに実行

`AlgorithmLearning.xcodeproj` を Xcode で開き、`LittleByLittleiOS` を選択します。iPhone シミュレーターで実行するか、Signing & Capabilities で自分の Personal Team を選んで接続中の iPhone に実行します。個人の Apple Account で端末テストができますが、プロビジョニングは7日ごとに更新が必要です。App Store などへの配布には Apple Developer Program への登録が必要です。iPhone ではアルゴリズム選択を画面上部のメニューにまとめ、説明カードを縦に表示します。
